## Проекты участка

В дашборде участок теперь делится на проекты. У каждого проекта свой ответственный, пароль, план, факт и закрытие месяца. При входе ответственный выбирает участок и свой проект. Администратор видит «Вилюй» одной группой с итогом по участку. В своде и отчётах можно выбрать «Все проекты участка «Вилюй»».

## Как построен план

- **Перевозка** и **Автотранспорт**: план взят из отчётов как есть: суточный график и суточные задания «рейсы × объём». На 23–30.09 по автотранспорту повторено задание 22.09.
- **Дробление**, **Сменные работы**, **Капремонт**: дневного плана в отчётах нет. Норма на день взята из фактической выработки. Для работ, которые шли почти каждый день, это средняя сменная выработка. Для эпизодических — средний темп плюс 10 %. Это демонстрационная реконструкция, реальный план загружается файлом того же формата.
- Если по плановой работе в день с данными нет выработки, ответственный вносит 0.
- Причины отклонений составлены по данным: работы ниже 90 % и дни без выработки, дожди, нехватка самосвалов, сход техники с линии. Комментарии за дни взяты из отчётов: погода и замечания по машинам.

## Особенности исходных данных

- В накопительной сводке км 1180–1190 данные только по 19.08. Поэтому у проекта «Сменные работы» в сентябре есть план, но нет факта, и мониторинг показывает дни без данных.
- В исполнительной схеме за 17.09 в графе «за сутки» указано 12 303 м² планировки откосов, но нарастающий итог не изменился. Объём учтён 21.09, когда вырос итог. Значения «за сутки», перенесённые со вчерашнего листа без роста итога, не учитываются.
- Скрытые листы 11–13.09 суточного отчёта по автотранспорту — незаполненные копии листа 10.09, они не используются.

## Пересборка

```
pip install openpyxl xlrd
python3 vilyuy/сборка/build_vilyuy.py
```

Демо-сборка хранит данные в браузере под отдельными ключами. Поэтому кэш основной версии дашборда вшитые данные не перекрывает.
