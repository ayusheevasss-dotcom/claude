# Отклонения ОУ и маркзамера по горной массе, январь–сентябрь 2026

**Основной результат:** `pptx/Сходимость_ОУ_и_маркзамера_2026.pptx` — 4 слайда в формате образца (`pptx/template.pptx`), тыс. м³; собирается `python3 pptx/build.py` из `calc/data.json`.

Черновик HTML-версии (`deck/`, артефакт https://claude.ai/artifact/BizNhgGocWvnHZX1vQWTKJ) устарел: в нём Δ = МЗ − ОУ, а в образце Δ = учёт − замер.

## Состав
- `calc/calc.py` — извлекает маркзамер из месячных справок (`2026-MM-DD.xlsx`), справки Токко за сентябрь 2026 и оперативный учёт из выгрузки «по месяцам 2026» → `calc/data.json`.
- `calc/tab.py` — сводные таблицы отклонений; `calc/rows.py` — строки таблиц для слайдов.
- `deck/project/` — файлы слайдов (deck.json + slides/*.html).

Исходные xlsx в репозиторий не кладутся: они были загружены в сессию (`/root/.claude/uploads/...`). Чтобы пересчитать, загрузите их снова и поправьте путь `U` в `calc.py`.

## Методика
- Как в образце: Δ = учёт − замер, отклонение % = Δ / замер. Допуск ±5%; «Внимание» — превышение не более 3 п.п., «Критично» — более 3 п.п.
- ОУ: Гросс = карьер Gross; КВ Гросс = MK Gross GL; Таборное = Tabornoe (включая VREZ); Токко = Tokko. Тонны — влажный вес.
- МЗ, Гросс/Таборное: тонны есть только в справках за авг–сен; за янв–июл пересчитаны из м³ по плотности ОУ.
- Стадии Гросс/Таборное по маркзамеру есть только за июль и август (лист «Лист3»; в сентябрьском файле — копия августа). Токко — стадии 1–3 за все месяцы.

## Слайды pptx (4)
1 общий: месяцы × Гросс, КВ Гросс, Таборный, Токко, всего · 2 Гросс по стадиям (июль–август) · 3 Таборный по стадиям · 4 Токко: месяцы × стадии 1–3.
